# Registration Fix

If you cannot register after connecting Supabase:

1. Open Supabase.
2. Go to SQL Editor.
3. Open `supabase/registration_fix.sql` from this app folder.
4. Copy all SQL.
5. Paste it into Supabase SQL Editor and click Run.
6. Stop the app with Control + C.
7. Start again with `npm run dev`.

The login page now shows exact error messages under the form.
